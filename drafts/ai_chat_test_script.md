# PlayMCP AI 채팅 테스트 스크립트 (토요일용, 복사-붙여넣기)

PlayMCP 사이트 → 로그인 → 'AI 채팅' 버튼 → 아래를 순서대로 입력.
도구 5개가 실제 호출되는지 확인하는 용도.

## 1. search_products — 일반 상품 검색 + 최저가
```
강아지 사료 2kg 검색해줘
```

## 2. find_pet_food — 조건 검색 (펫 버티컬)
```
고양이 사료 중에서 그레인프리인 것만 찾아줘
```

## 3. compare_nutrition — 두 상품 영양 비교
```
오리젠 오리지날 독 2kg이랑 로얄캐닌 미니 어덜트 2kg 영양성분 비교해줘
```

## 4. check_price_timing — 타이밍 판단
```
오리젠 오리지날 독 2kg 지금 사도 돼?
```
(처음엔 "가격 데이터가 아직 N건뿐"이라는 응답이 정상 — search/find 호출이 쌓이면 판단이 붙음)

## 5. get_buy_link — 구매 링크 (수익화 레이어)
```
1번에서 찾은 오리젠 오리지날 독 2kg 구매 링크 줘
```

## 현실적인 쇼핑 플로우 (4개 도구 연결 테스트)
```
강아지 사료 찾아줘 → 두 개 골라서 영양 비교해줘 → 싼 게 지금 사기 좋은 타이밍인지 봐줘 → 구매 링크 줘
```

---
체크: 각 답에 도구 호출 흔적(검색 결과 표, 타이밍 판정 문구, 구매 링크)이 보이는지.
실패 시: 임시 등록 상태인지, 도구함에 서버가 담겼는지 먼저 확인.
